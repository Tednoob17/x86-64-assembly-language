# x86-64-assembly-language

This repository contains an interactive book about x86-64 assembly language.
The main content lives in `src/`, and quiz sources live in `quizzes/`.

To build the book, run `mdbook build` from the repository root once mdBook is
installed.

Quiz examples are provided under `quizzes/examples/` to document the question
format used by the interactive quiz system.

There is also a lightweight spelling-check helper in `ci/spellcheck.sh` for
the Markdown sources.
